Guida Rapida: Automazione Home Assistant

1
Automazione Webhook
YAML

In Home Assistant vai su Impostazioni ➔ Automazioni ➔ Crea Automazione, tocca i 3 puntini ➔ Modifica in YAML: 

alias: "Apri Portone Aurora"
trigger:
  - platform: webhook
    webhook_id: "apriporta_aurora"
    allowed_methods:
      - POST
    local_only: false
action:
  - service: switch.turn_on
    target:
      entity_id: switch.portone
  - delay: "00:00:01"
  - service: switch.turn_off
    target:
      entity_id: switch.portone
mode: single
2
Esperienza per l'Ospite

Semplicità assoluta ispirata al design Apple:

  • L'ospite riceve il link con un unico pulsante "APRI PORTA".
  • Nessun codice da ricordare: l’accesso avviene dal link personale.
  • Il server contatta Home Assistant via Webhook o REST API.
  • L'elettroserratura scatta all'istante per permettere l'ingresso.
