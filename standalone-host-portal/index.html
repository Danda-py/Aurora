Come funziona la trasmissione ministeriale:

Per consentire ad Aurora l'invio telematico automatico tramite Web Service SOAP della Polizia di Stato, inserisci qui sotto le credenziali assegnate alla struttura dalla Questura di Sondrio. La WsKey (chiave web service) si genera accedendo al portale alloggiatiweb.poliziadistato.it nel menu Amministrazione > Web Service > Genera Chiave.

Se non possiedi ancora la WsKey o preferisci il caricamento manuale, puoi sempre scaricare il file .txt conforme ministeriale da ciascuna prenotazione qui sotto e caricarlo direttamente sul portale Alloggiati Web.

Sito Host Indipendente & Standalone

Controlla il portale, genera chiavi digitali e aziona la serratura da un pacchetto autonomo scaricabile in formato .ZIP

Questo archivio contiene l'applicazione web completa per l'Host, pronta per essere eseguita in locale su qualsiasi PC aprendo index.html oppure pubblicata su qualsiasi server web autonomo. Si collega direttamente al backend di Aurora in Valtellina.

Scarica Portale Standalone (.ZIP)

Integrazione e Chiamate API Standalone:

  • GET /api/passes Recupera in tempo reale tutti i pass ospiti attivi con stato e scadenze.
  • POST /api/channels/sync-now Sincronizza istantaneamente tutti i canali iCal (Airbnb, Booking.com, Vrbo, Bed-and-Breakfast.it).
  • PUT /api/property/config Aggiorna coordinate GPS, raggio geofence (50m primo check-in) e istruzioni impianti.
  • POST /api/hass/unlock Invia l'impulso ON alla serratura smart per l'apertura immediata.
